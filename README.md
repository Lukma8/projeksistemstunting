
## 📝 Deskripsi
Proyek ini adalah sistem informasi berbasis web yang dirancang untuk memantau pertumbuhan anak guna mendeteksi dan mencegah stunting sejak dini. Sistem ini memungkinkan petugas kesehatan atau admin untuk mencatat data fisik anak (tinggi badan, berat badan, usia) dan memberikan analisis status gizi berdasarkan standar kesehatan.

## ✨ Fitur Utama
- **Manajemen Data Anak**: Input, ubah, dan hapus data identitas anak.
- **Pencatatan Antropometri**: Rekam riwayat tinggi badan dan berat badan secara berkala.
- **Klasifikasi Status Gizi**: Perhitungan otomatis status stunting berdasarkan standar WHO/Kemenkes.
- **Laporan & Grafik**: Visualisasi perkembangan pertumbuhan anak melalui grafik.
- **Manajemen Pengguna**: Level akses untuk Admin, Petugas Kesehatan, dan Orang Tua.

## 🛠️ Teknologi yang Digunakan
- **Bahasa Pemrograman**: PHP (Laravel Framework) / Python (Django) *[Sesuaikan dengan kode Anda]*
- **Database**: MySQL / PostgreSQL
- **Frontend**: Bootstrap 5 / Tailwind CSS
- **Library Grafik**: Chart.js
- **Icons**: Font Awesome
